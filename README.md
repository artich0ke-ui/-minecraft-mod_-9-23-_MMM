# TopazCraft

Учебный проект по дисциплине «Инструментальные средства разработки программного обеспечения».

## Команда CodeCrafters

- Макаров (И9-23Б) — организация работы, сборка релиза
- Маслов (И9-23Б) — программная часть, рецепты, генерация руды
- Малеев (И9-23Б) — текстуры, локализация, тестирование

## Цель проекта

Разработать модификацию для Minecraft на платформе Fabric, которая добавляет новый блок — «Светящийся блок топаза». Блок излучает свет, создаётся из девяти самоцветов топаза и используется для освещения и украшения построек.

## Планируемые возможности

- Новая руда топаза, генерируемая в мире
- Переплавка руды в самоцвет топаза
- Крафт блока из девяти топазов
- Уникальная текстура и название на русском и английском языках
- Уровень освещения 15
- Добыча только железной или алмазной киркой

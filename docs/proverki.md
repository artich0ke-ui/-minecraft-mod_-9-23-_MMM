# Таблица проверок (ЛР 11–12)

Заполните столбец «Фактический результат» после запуска `runClient` и проверки установленного JAR.

| № | Проверка | Начальное условие | Действие | Ожидаемый результат | Тип | Фактический результат |
|---|---|---|---|---|---|---|
| 1 | Загрузка мода | Клиент запущен | Открыть мир | Игра запускается без ERROR в журнале | + | |
| 2 | Получение командой | Мир с читами | `/give @s topazcraft:topaz_block` | Блок появился в инвентаре | + | |
| 3 | Творческий инвентарь | Творческий режим | Открыть «Строительные блоки» | Топазовый блок есть во вкладке | + | |
| 4 | Название | Блок в инвентаре | Навести курсор | Подсказка «Топазовый блок» | + | |
| 5 | Текстура | Блок в мире | Осмотреть все стороны | Видна жёлто-оранжевая текстура, нет чёрно-фиолетового | + | |
| 6 | Рецепт | Выживание, верстак, ингредиенты | Выложить схему из README | Результат — Топазовый блок | + | |
| 7 | Неверный рецепт | Верстак | Выложить схему с ошибкой (убрать алмаз) | Результата нет | − | |
| 8 | Свет | Блок в тёмной пещере | Установить блок | Вокруг блока светло (уровень 8) | + | |
| 9 | Добыча киркой | Выживание, каменная кирка | Сломать блок | Выпадает Топазовый блок | + | |
| 10 | Добыча рукой | Выживание, пустая рука | Сломать блок | Предмет не выпадает | − | |
| 11 | Поведение | Пустая рука | ПКМ по Топазовому блоку | Одно сообщение в чате | + | |
| 12 | Чужой блок | Пустая рука | ПКМ по камню | Сообщения нет | − | |
| 13 | Установка блока рядом | Блок в руке | Поставить блок на Топазовый | Блок ставится, сообщения нет | − | |
